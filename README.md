# Akıllı Görev & Proje Yönetim Sistemi (Trello Clone)

Ekiplerin görev oluşturduğu, takip ettiği ve kanban mantığıyla çalışan çok platformlu iş yönetim sistemi[cite: 1].

## 🚀 Canlı Servisler & API
- **Live Backend API:** `https://trello-clone-backend-cs8r.onrender.com/api`
- **Database:** PostgreSQL (Render Cloud)[cite: 1]
- **Email Gateway:** Resend HTTP API

## 🛠 Kullanılan Teknolojiler & Mimari
- **Backend:** Node.js, Express, PostgreSQL, Prisma ORM, JWT Authentication, Helmet, Express Rate Limit, Resend API[cite: 1].
- **Mobil App:** React Native, Expo, Axios, EAS Build[cite: 1].
- **Güvenlik:** Bcryptjs şifre hashing, Rate-limiting, CORS & Helmet koruması[cite: 1].

## 📱 Özellikler
- **Auth & Güvenlik:** JWT tabanlı oturum yönetimi ve 6 haneli e-posta doğrulama kodu akışı[cite: 1].
- **Görev Yönetimi:** CRUD işlemleri ile durum takibi (TODO, DOING, DONE)[cite: 1].
- **Mobil Canlı Dağıtım:** Expo EAS Build ile oluşturulmuş bağımsız Android APK[cite: 1].
